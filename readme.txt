网站询盘的后台：接收、防垃圾、来源渠道、存储、通知邮件、钉钉。表单外观由主题负责。

== Changelog ==

= 0.4.1 =
* 访客不再等 AI：询盘存好就答复提交成功，IP/域名查询、AI 判断和邮件钉钉在后台跑（PHP-FPM 下同一请求答复后继续，否则交给 WP-Cron 立即执行），通知只会晚几十秒；后台中途断开 3 分钟后按普通询盘补发。
* 转化（?sent=）在提交时按留言快速判：群发模板话术≥2 句且没提设备的不带；其余带上，后台 AI 再判出的垃圾不能撤回已记的转化。
* 询盘设置加「测试连接」按钮：用已保存的设置发两条样例（真实买家、群发骗局），显示结果、星级和耗时，接口报错原样显示。

= 0.4.0 =
* AI 判断与背调（询盘设置：Base URL、API Key、模型、等待秒数（默认 30）；OpenAI 兼容 /chat/completions，只认 https）。服务器先查 IP 国家与网络归属（机房/VPN）、邮箱是免费邮箱还是公司域名、公司域名官网标题和注册日期（RDAP）、来源渠道和页面，连同本站产品清单交给 AI；能联网的模型会自行搜索核实。
* AI 判垃圾：存下并标无效（原因写明），不发邮件，钉钉只推「拦截一条垃圾询盘，原因 …」，不给 ?sent=、不计转化；误判点「恢复有效」会补发一次邮件。
* AI 判正常：1–5 星优质度和一句背调写进邮件（标题【★★★★☆】+ 正文蓝框）、钉钉（标题带星、第一行 AI 背调）和后台列表。
* 「客户信息真实、只是产品对不上」不算垃圾，按低星处理。
* AI 没设置、出错或超时：改用 0.3.0 的规则判断。主题可用 achord_inquiry_ai_catalog 过滤器补充产品说明。

= 0.3.0 =
* 自动标记疑似垃圾询盘（询盘设置里可关，默认开）：留言里有两句以上群发骗局套话（索要目录/价目表、「你是负责人吗」、约 Zoom/Teams 会议、MOQ 等）且没提设备本身，或从机房/VPN 网络提交且没提设备的，照常存下、照发邮件和钉钉，但标题前加【疑似垃圾】、自动标为无效（原因写明）、不给 ?sent= 感谢页，所以不算 GA4 generate_lead 和广告转化。真客户在列表点「恢复有效」。
* 网络归属查 ipinfo.io/<ip>/org，按 IP 缓存一周。

= 0.2.1 =
* 只写无效标记的校验改为对照文章接口自己的可写字段清单：WordPress.com 连接器经代理转发时带的额外参数不再被误拒；被拒时错误信息列出是哪些字段。

= 0.2.0 =
* 询盘可「标为无效」（垃圾、与产品无关、测试）：后台列表行操作「标为无效 / 恢复有效」，列表显示「无效 · 原因」；管理员可经接口只写 meta.<rest_record>_invalid 一个字段（其他字段仍只读），记录里多出 invalid。询盘本身、状态、通知都不动。

= 0.1.0 =
* 从起重机站主题抽出：提交处理、Turnstile、每 IP 十分钟 5 条限流、黑名单（存成已拦截草稿）、来源渠道/访问设备/IP/国家、后台「询盘」列表和详情、只读接口、经典卡片通知邮件、推钉钉、设置 → 询盘设置。
* 主题用 add_theme_support('achord-inquiry', [...]) 声明后才启用；没声明时插件什么都不做。
